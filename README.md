# 🎓 SSC Countdown

> ⏳ **Track your SSC journey — one second at a time.**

A lightweight, fast and privacy-friendly web app for students in Bangladesh.  
Select your **SSC Batch** and instantly see your academic status, countdown and progress in a modern glass UI.

<p align="center">

**✨ Simple • ⚡ Fast • 🎨 Modern • 🔒 Private**

</p>

---

## 🚀 Features

| 🎯 Feature | 💡 What it does |
|---|---|
| 📚 **Smart Class Status** | Automatically calculates current class from SSC batch |
| ⏳ **Live Countdown** | Days, hours, minutes & seconds |
| 📅 **Fixed Exam Date** | Countdown starts from **February 1** of the batch year |
| 📈 **Academic Progress** | Visual progress toward SSC |
| 💬 **Motivational Quotes** | Rotating study quotes |
| 🪟 **Glass UI** | Modern liquid-glass design |
| 🌙 **Dark / ☀️ Light** | Theme switching with saved preference |
| 📱 **Responsive** | Mobile, tablet & desktop |
| 🔒 **Privacy Friendly** | No accounts or personal data required |

---

## 🎓 Example

```text
SSC 2027 → Class 10
SSC 2028 → Class 9
```

## 📅 Countdown Note
